# Runtime Codemap: Walls & Siege

Last Updated: 2026-11-13 17:29:40 (KST)

> Purpose: Class map for castle construction, fall damage, siege weapons, and enemy siege AI. | Parent: [codemap/README](README.md) | Related: [CombatAndSquads](CombatAndSquads.md), [design/WallsAndSiege](../design/WallsAndSiege.md)

Base path: `Assets/_Project/Scripts/Runtime/`. Assembly: `ProjectNeo.Runtime`. Namespace: `ProjectNeo.<Folder>`.

Shared ladders (`SIEGE-04`, `feature/siege-04`): pure `Siege/LadderTraffic<T>` enforces FIFO single occupancy for both directions and teams. `SiegeLadder` keeps legacy enemy raising/climbing APIs while routing their occupancy through the shared actor queue; it also handles allied raising and friendly-use automatic-topple protection. `Siege/LadderTraveller` is added at runtime by allied `UnitCombatAI` or `PlayerInputController`, without prefab/scene edits. It selects a reachable ladder route only when the ordered destination lacks a complete walking path, drives approach/ascent/descent, defers orders received aboard, and restores NavMeshAgent/CharacterController or hands interruption/death to `UnitFallController`. Player uses tap F boarding, W/S climbing and hold F raising/toppling; `SiegeSettings.LadderTapSeconds` controls the temporary 0.25s tap threshold. `CharacterActor.IsOnLadder` prevents new attacks and cancels pending impacts while remaining damageable. GameFlowHud/SiegeStatusHud show contextual traversal hints. [Verification](../history/SIEGE/SIEGE-04.md).

One-cell stairs (`SIEGE-03`): shared `Data/ConstructionPrototype/Stairs.asset` uses a 1×1 footprint and 3m height. `ConstructionWorld.SetPose` scales the existing normalized ramp collider and Visual to 3×3×3m; no mesh or material change is needed for size. The ramp mesh (`Art/Placeholder/ConstructionRamp.asset`) is generated by `Editor/ConstructionRampMesh` with per-face vertices for flat shading (`ART-01`; menu `ProjectNeo/Setup/Flatten Stair Shading` rewrites it in place). `Editor/OneCellStairsMigration` retains high landings while moving initial seeds in ConstructionPrototype, WallCommandPrototype, SiegePrototype and Game (7 stairs total); repeated execution does not move them again. Setup generators now emit the new locations. Humanoid NavMesh maximum slope is 46° to admit the exact 45° ramp; `Characters/PlayerControlSettings.MaximumWalkSlope` defaults to 46° and is applied by PlayerInputController.Awake. Four Game PlayMode cases cover both traversal directions, rotations, two tiers and disconnection after stair destruction. [History](../history/SIEGE/SIEGE-03.md).

Construction wheel input (`BUG-build-camera-zoom`): ConstructionCameraController uses normalized scroll steps directly; only Windows editor/player with KeepPlatformSpecificInputRange divides by 120. GameFlowPlayTests.ConstructionWheelInput_UsesNormalizedStepsAndRestoresCamera covers actual input → Update → zoom/reset; user confirmed physical wheel zoom works (2026-11-13). [History](../history/BUG/BUG-build-camera-zoom.md).

Grid display (`BUG-build-grid-lines`): BuildCameraSettings.MinimumGridLinePixels (default 1.5px) is exposed through ConstructionCameraController. BuildGridView updates its cached mesh before each URP Game camera render, computing perpendicular pixel widths separately for the two grid axes; original world line width remains the minimum. Cell centers/spacing, occupancy and picking stay unchanged. Cameras without an orthographic construction controller use original width. [History](../history/BUG/BUG-build-grid-lines.md).

| Folder | Key Classes | Role |
|---|---|---|
| Walls | `ConstructionProgress` | Construction duration and stage pacing calculations. Not yet linked to runtime placement. |
| Walls | `BuildGridDefinition`, `BuildPieceDefinition`, `BuildLayout` | Grid dimensions, `MaxLevels` (default 1), piece footprint, height, HP, and prefab definitions. Pure C# occupancy, rotation, boundaries, fixed gate zone checks, and detached stair connectivity queries. Layer stacking: keyed by `(x, level, z)`, pieces snap atop target column. `BuildPlacement.Level` and `Elevation` track layer and floor height. `Check(..., out level, out elevation)` validates placement; `Remove` followed by `Settle(dropped, unsupported)` collapses or removes unsupported pieces. `At(cell)`, `At(cell, level)`, `Top`, `ColumnHeight`, `IsCovered` query vertical layers. |
| Walls | `ConstructionWorld`, `PlacedStructure` | Spawns placement instances and colliders, elevates overlapping living units to new top surfaces without damage, piece health/destruction events, aggregates batch asynchronous NavMesh updates. |
| Walls | `PlacementViewSettings`, `PlacementController`, `BuildGridView` | Translucent preview materials/colors, mouse picking, placement, cancellation, rotation, grid rendering. Preview has zero collision/occupancy/NavMesh impact. |
| Walls | `SiegeWeaponDefinition`, `MountLayout`, `PlacedSiegeWeapon`, `ISiegeWeaponModule` | Unified siege weapon framework. Definition asset (ID, name, size, prefab), pure C# mount point occupancy rules (piece ID + mount ID), shared weapon entity container, extensible behavior interface. No cannon-specific hardcoding. |
| Walls | `BuildCameraSettings`, `ConstructionCameraController` | Orthographic camera angle, size, initial azimuth, rotation step, and transition duration settings. Q/E orbits pivot by 90 degrees while maintaining world/grid coordinates. Game asset enables middle-click drag pan, scroll zoom, Home reset, with tunable start pivot, sensitivity, and zoom clamps. |
| Walls | `FallSettings`, `FallDamageRules`, `UnitFallController` | Height-based fall damage calculation and collapse dropping/landing. Supports NavMeshAgent and CharacterController; restores navigation upon landing. `LiftForConstruction` teleports units harmlessly to new top surfaces upon placement. |
| Walls / UI | `ConstructionSandbox`, `ConstructionHud` | Test scene movement and foundation destruction buttons; uGUI/TMP piece picker and status HUD. |
| Walls | `WallCommandSandbox` | Integrated test scene Tab view toggle. Swaps construction and 1st-person camera, input, and HUD while retaining terrain and orders. Activates units after World builds NavMesh. |
| Siege | `BuildBudget`, `SiegeOutcomeRules`, `SiegeLadderState` | Pure C# siege rules. Temporary build budget deduction/refund, win/loss evaluation (defeat prioritizes simultaneous victory, Q-09) and retreat trigger, ladder state machine (placed → raising → raised, single climber queue, toppling). |
| Siege | `SiegeSettings` | Settings asset for budget, ladder timings/distances, enemy tick intervals, hotkeys (F topple, Tab view, R restart). |
| Siege | `SiegeLadder`, `PlaceholderLadderView` | Fixed ladder slots along wall perimeter. Active only when wall piece exists at slot. Shared FIFO occupancy for enemies/allies/player; existing enemy raiser APIs retained. Friendly occupancy/requests protect against automatic toppling; nearby hostile defenders still block pushing, while enemy ladder occupancy alone does not. Visualized via placeholder bar under `Visual`. |
| Siege | `SiegeAttackerBrain` | Per-enemy siege decision AI. Delegates to `UnitCombatAI.Engage` if walkable ally exists; otherwise executes role-specific siege behaviors (`SiegeAttackerRole`: Ladder=0, GateBreaker=1, Archer=2, WallBreaker=3). WallBreaker delegates structure handling to `WallBreakerAttack`, immediately reselecting invalidated targets after navigation settles. Movement and attacks executed via `UnitDirective`. Ladder grunts redirect to gate if no ladders exist. `Retreat()` navigates unit off-map, setting state to `Fled` (excluded from active enemy tally). |
| Siege | `WallTargetCandidate`, `WallTargetStrategy`, `NearestWallTargetStrategy` | Data-selected ScriptableObject target strategy. Pure candidate ID/distance inputs; nearest valid collider distance wins, stable placement-ID tie break. Invalid distances ignored. Other strategies can be assigned through `WallBreakerSettings`. |
| Siege | `WallBreakerSettings`, `WallBreakerAttack` | Per-prefab strategy and approach clearance/snap data. Candidate walls/gates must be level 0 (stairs excluded); tries four base faces and rejects incomplete paths, elevated snaps, and endpoints outside attack range. Holds/retries if none reachable; existing actor attack cadence/signals damage the wall. Rebuilds pause structure attacks. Assault/retreat/deactivation clears selection. Prefab `Prefabs/SiegePrototype/enemy_wall_breaker.prefab`; assets `Data/SiegePrototype/WallBreaker.asset`, `NearestWall.asset`. |
| Siege | `SiegePrepController`, `SiegeDirector` | Prep phase utilities (budget validation, demolition/refund, click-placement of squads) and match coordinator (spawns squads from `SiegeSettings`, orchestrates prep → battle → outcome, camera swaps, enemy activation, win/loss). Not connected to persistent run flow. |
| UI | `SiegeHud`, `SiegeStatusHud` | Test prep overlay, phase banners, troop count, and outcome screens. |
