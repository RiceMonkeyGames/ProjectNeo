## Goal & Scope
Keep licensed third-party assets (Synty packs and other paid content) out of the main repository so ProjectNeo can be made public later without redistributing them. Set up before any licensed asset was committed to the main repository, so no history rewrite is needed. No game code changes.

## Implemented Artifacts

- `.gitattributes`: Unity template from the main repository with path rules adjusted to the submodule root (`Plugins/**` linguist-generated; `Packages/packages-lock.json` rule removed). **Git LFS is not used**: every `lfs` rule became `binary` and the `[attr]lfs` macro was removed; repository-local LFS hooks were uninstalled.
- `.gitignore`: OS/editor junk, `*.unitypackage`, Blender backups, Asset Store tools, Rider plugin output.
- `README.md` (+ Unity-generated `README.md.meta`): private/no-redistribution notice, no-LFS note, `.meta` rule, commit order.

## Decisions
- **No LFS for the asset repository** (user, 2026-11-16): initial import is ~1.36 GB, of which ~965 MB are LFS-type files (fbx/png/...). GitHub's free LFS tier (1 GB storage, 1 GB/month bandwidth) would be exhausted by one teammate clone, and third-party packs rarely change, so LFS's history benefit is small. Regular git: largest file is `Demo.unity` (33 MB), none over 100 MB.
- **Trim bundled Unity UI Extensions** (user, 2026-11-16): the HUD pack ships an old `com.unity.uiextensions` copy that does not compile on Unity 6000.6 (`UIPrimitiveBase` missing `ILayoutElement.maxWidth/maxHeight`; `FlowLayoutGroup`/`TableLayoutGroup` old `SetLayoutInputForAxis` signature; `ColorPickerPresets`/`ExtensionMethods` obsolete `GetInstanceID`). Deleting it entirely would break the HUD: `AssetDatabase.GetDependencies` found 93 HUD prefabs/scenes (all 15 demo scenes) and 10 HUD materials depending on it, but only on four library files. Kept: `Runtime/Scripts/Effects/UIParticleSystem.cs`, `Runtime/Scripts/Utilities/ShaderLibrary.cs` (used by `UIParticleSystem`), `Runtime/Resources/Shaders/UIAdditive.shader`, `UIMultiply.shader`, `UI Particle Add.shader`, plus `Runtime/UnityUIExtensions.asmdef`, `LICENSE.md` (BSD-3), `README.md`. The other 208 files were moved to the OS trash through `AssetDatabase.MoveAssetsToTrash`; kept files keep their `.meta` GUIDs. An interim `UIPrimitiveBase` patch was dropped with that file. If more of the library is needed later, install a Unity 6 compatible release via the Package Manager rather than restoring the bundled copy.
- **Stray import**: `Assets/Unity UI Extensions` initially landed in the main repository root; it was moved under `Assets/ThirdParty` with `AssetDatabase.MoveAsset` before any commit.
