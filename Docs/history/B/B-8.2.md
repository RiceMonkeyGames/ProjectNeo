### 2026-11-13: Ally squad morale wired into the Game scene

- Assignee: youngho. Branch `feature/b-8.2`. Scope fixed by Q-44 (ally squads only; enemies have no morale; Collapse/Awaken combat effects and HUD split to COMBAT-03).
- Added:
  - `Morale/GameSquadMorale`: added at runtime by `GameBattleController.Awake` when `GameBattleSettings.Morale` is set, so `Game.unity` was not edited. Handles battle start/end/next prep itself via `GameFlow.PhaseChanged`. Feeds member/captain deaths, last main gate collapse, nearby wall collapse (once per squad per frame for cascades), nearby rout, Rally/Contagion nearby changes. Routed squads (captain included) are detached from orders and run to a computed retreat point (castle-structure bounds, edge opposite enemy `Outward`, 9m inset, NavMesh-sampled); exit (hidden) on arrival within 2.5m or after 20s. Next preparation: exited units reappear at the retreat point, are reattached and walk to their squad gather point.
  - `Data/GameFlow/Morale.asset` via `Editor/MoraleSetup` (menu `ProjectNeo/Setup/Connect Morale To Game Battle`), linked into `Battle.asset`; `GameBattleSetup` reconnects it on rerun.
  - `MoraleSettings`: default full-squad loss `150/0.9 ≈ 166.7`; rout movement fields (`RetreatInset`, `RetreatArrivalDistance`, `RetreatTimeout`). `SquadMorale` snaps values below 0.001 to 0.
  - `Squad<TUnit>.Morale`: run squad carries morale between battles (new squads start at 150 on first use).
  - `SquadCommandCenter.Detach/Reattach/IsDetached`.
  - `BattleResult.EnemiesRetreated`/`AddRetreat`; `RunUnitBinding.CreateResult` and `GameRunLink.TryFinish` optional `isFled`/`retreats` (death first). `GameBattleController` passes `HasFled` and Q-30 retreat counts.
