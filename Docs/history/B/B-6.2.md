## Implementation

- `WallTargetStrategy` is selected through `WallBreakerSettings`; `NearestWallTargetStrategy` compares valid squared collider distances and breaks ties by placement ID. Candidate structs contain no scene references. Future priorities replace the strategy asset without adding branches to the brain.
- `WallBreakerAttack` selects only living level-0 walls/gates, excludes stairs, checks four footprint faces for a complete ground path and an endpoint within attack range. No reachable base means Hold and interval retry. Invalidated targets trigger re-selection on the next eligible brain update; navigation rebuilds pause decisions/structure damage.
- A path to any ally switches to existing Engage. Structure strikes use the existing CharacterActor attack cadence/start event and Attack/minimum damage. Assault, retreat and deactivation clear the structure selection.
- `SiegeAttackerRole.WallBreaker = 3` appends to the serialized enum. Existing ladder/gate/archer values and behaviors remain intact.
- Editor-only `WallBreakerSetup.CreateAssets`, menu `ProjectNeo/Setup/Add Wall Breaker Assets`, creates `Assets/_Project/Prefabs/SiegePrototype/enemy_wall_breaker.prefab`, `Assets/_Project/Data/SiegePrototype/WallBreaker.asset` and `NearestWall.asset`, using Editor APIs. It registers the prefab in the SiegePrototype roster at **0** by default, keeping existing encounters unchanged and allowing Inspector opt-in. Repeated setup retains existing assets/counts. The prefab reuses hostile-melee stats and gate-breaker placeholder visuals; distinctive production art is outside scope.
