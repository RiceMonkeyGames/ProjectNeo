  - Facility model scale is fitted to a footprint, so door sizes differ between buildings. Posts and stair ends of hillside houses go into the ground.
  - Round-three changes (grid toggle, hidden ground, player model, first-person body, sunk houses, decorative houses) have no automated test run yet; known risks are Game PlayMode tests that look for the ground renderer or player renderers, and NavMesh paths near the new decorative houses.
