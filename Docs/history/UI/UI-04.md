## Implementation

- Font: `Assets/_Project/Art/Fonts/NotoSansKR-Regular.otf` (Noto CJK subset OTF from the official `notofonts/noto-cjk` repository, SIL OFL 1.1, license text `NotoSansKR-OFL.txt`). `KoreanFontSetup` (menu `ProjectNeo/Setup/Korean Font`) creates `NotoSansKR SDF.asset` (dynamic, multi-atlas, 2048², sampling 36, padding 4), pre-fills it with ASCII, common symbols and the 2,350 KS X 1001 Hangul syllables from `KoreanCharset.txt`, and adds it to the global TMP fallback list in `TMP Settings.asset`. Existing labels keep LiberationSans for Latin text and fall back to Noto Sans KR for Hangul, so no scene font references changed. The asset is about 17 MB (two atlas pages serialized as text).
- Runtime code: player-facing strings in 41 runtime files (HUD, facilities, equipment, squad organization, perks, unlocks, morale, siege, title, reward, score) were rewritten in Korean in place. Developer-facing text (exceptions, logs, save validation reasons, catalog validation) stays English. `PerkWindowModel.StatName` now names every stat. `EnemyIntel.DisplayName` maps the known enemy prefabs to Korean (사다리병, 궁수, 성문 파괴병, 성벽 파괴병, 비행병, 고공 비행 궁수) and keeps the old title-case fallback for unknown prefabs.
- Authored content: `KoreanUiMigration` (menu `ProjectNeo/Setup/Migrate UI To Korean`, plus `Audit()` and `Dump()`) rewrote 272 scene TMP captions in 8 scenes and definition display strings (display names, Ascension level descriptions, unlock entry names) through Editor APIs. Object names, ids, asset names and gameplay values are unchanged. The final audit reports no unmapped English text besides the kept `ProjectNeo` title and `HP -- / --`.
- Setup scripts: captions and display names in the Editor setup generators now match the Korean data, so re-running a setup does not bring English back. `ConstructionPrototypeSetup.Button`/`SiegePrototypeSetup.Button` take an optional `caption` and `GameFlowSetup.Facility` an optional `sign`, so GameObject names (`Button_Wall`, `Tavern`, ...) stay English for lookups. `EnglishUiMigration` (UI-02) is left in place but no longer matches anything.
- Tests: EditMode and PlayMode expectations that read UI text now expect the Korean strings. `GameFlowPlayTests.AuthoredTitleAndPreparationUi_UsesEnglishAndProjectFonts` became `..._UsesKoreanAndHangulFont`: it checks that Noto Sans KR is a global TMP fallback, that every Hangul label in `Title` and `Game` can be drawn (`TMP_FontAsset.HasCharacters` with fallbacks), and that more than 10 authored captions are Korean. `EnemyIntelTests` adds an unknown-prefab fallback case.

## Manual Verification Guide

1. Open `Assets/_Project/Scenes/Title.unity`, press Play. Expect Korean slot rows (`슬롯 1: 지휘관 Lv ...`), buttons `이어 하기`, `새 게임`, `해금`, `고른 슬롯 삭제`, `종료`. Open `해금` and check the track titles and entries, then `닫기`.
2. Start `새 게임` (pick `승천 0`, `런 시작`). In `Game.unity`: the top shows `준비 - 스테이지 1`, the prep clock `준비 시간 ...시간 남음`, the left squad panel and enemy list (`다음 전투 - 적`, `사다리병 × N`).
3. Walk to each building and press `F`: 상점, 주점, 훈련장, 대장간, 영웅관, 건설 작업대. Read headers, rows, buttons and refusal messages (e.g. buy without gold). Press `I` (장비) and `O` (부대 편성), `K` (특성). Close with `Esc`. Look for clipped or overflowing text.
4. Hold `B` to start the battle. Check `전투 - 스테이지 1`, `적 N - 아군 N`, wave and cannon prompts (`대포 잡기`), ladder push text and the boss bar. Finish a battle and read the victory reward or defeat result text.
5. Optional: open the prototype scenes (`ConstructionPrototype`, `SiegePrototype`, `WallCommandPrototype`, `SquadCommandPrototype`) and check the HUD captions.
6. Reset: stop Play Mode. To discard a test run, delete the test slot from the title (`고른 슬롯 삭제` twice).
