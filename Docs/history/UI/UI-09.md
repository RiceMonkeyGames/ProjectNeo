## Manual Verification Guide

1. `Assets/_Project/Scenes/Game.unity` (start a run from Title). In preparation, order a wall or cannon at the construction station but do not spend time on it, then look at the battle-start hint: expect `! 끝나지 않은 작업 1개 - 시작 안 한 1개는 전투가 시작되면 없어지고 환불됩니다` in yellow.
2. Press `I`, switch to a hero with skills and toggle Auto: the notice reads `자동 사용 꺼짐: 부대를 고르고 Alt + 스킬 키로 시킵니다.`; the hero skill help mentions 부대.
3. In battle with no squad selected, press a skill key with Alt: expect `먼저 부대를 선택하세요.`
4. In the perk window (`K`) or the equipment skill list, read 전투 함성 and 결집: their descriptions say 자기 부대.
5. Reset: stop Play Mode; delete the test slot from the Title slot window if needed.
