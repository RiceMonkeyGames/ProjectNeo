## Implementation

- `TitleScreen`: `mainMenu`/`slotMenu` references (`ConfigureMenus`), `OpenSlotMenu()`, `BackToMain()` (also closes the expedition and unlock windows), `IsSlotMenuOpen`. The Title starts on the main menu. `StartGame()` (New Game) now always opens the expedition screen via `OpenExpedition()`, which hides the main and slot screens so it reads as a step of its own; `CloseExpedition()` (its back button) returns to the slot window and closes an open unlock window. The run starts from its depart button (`AscensionPicker.StartSelected` → `BeginRun`). Older scenes without the menu references behave as before.
- `GameFlow.ReturnedFromRunEnd` / `TakeReturnedFromRunEnd()`: set when `ReturnToTitle` leaves `RunResult` or `Ending`, cleared by `StartRun`. When set, the Title opens the slot window and the expedition screen of the last active slot instead of the main menu.
- `TitleMenuSetup` (menu `ProjectNeo/Setup/Split Title Main Menu And Slot Window (UI-05)`, re-runnable): `Panel` keeps the logo, adds `Button_Start` (게임 시작) and keeps `Button_Quit`; new `SlotPanel` (copied layout, wider, header 슬롯 선택) holds the three slots, status, continue, new game, delete and `Button_Back` (뒤로). The Ascension window becomes the expedition screen: header 출정 준비, level row, rules, `Button_Unlocks` (moved here), depart (출정, formerly 런 시작) and back (뒤로, formerly 취소). `UnlockOverlay` is drawn above `AscensionOverlay`. The expedition overlay is clear and its window opaque like the other panels; back is rewired from `AscensionPicker.Close` to `TitleScreen.CloseExpedition`. Object names other than the new ones are unchanged.
- Tests: Title paths moved from `Panel/...` to `SlotPanel/...`; New Game callers now press depart; new `GameFlowPlayTests.Title_StartsOnMainMenu_StartOpensSlotWindow_BackReturns` (main first, slot window contents, New Game opens the expedition screen without leaving the Title, unlocks open above it, back closes everything); the defeat-to-title test checks that the expedition screen opens on return; `TitleUnlockPlayTests` opens unlocks from the expedition screen.

- Korean font fix: Hangul rendered as garbage after the agent restored `NotoSansKR SDF.asset` to its committed version while the Editor had grown its dynamic atlas in Play Mode (glyph table and atlas pixels out of sync). `KoreanFontSetup` now clears the font data, refills `KoreanCharset.txt` and sets the atlas to `Static`, so Play Mode no longer writes to the asset. All 466 Hangul characters used in runtime and Editor strings are in the charset; characters outside it will not render, so add them to `KoreanCharset.txt` and re-run `ProjectNeo/Setup/Korean Font`.

## Manual Verification Guide

1. Open `Assets/_Project/Scenes/Title.unity`, press Play. Expect only the logo, `게임 시작` and `종료`.
2. Click `게임 시작`: the slot window (`슬롯 선택`) shows three slots, `이어 하기`, `새 게임`, `고른 슬롯 삭제`, `뒤로`, and no `해금`. `뒤로` returns to the main menu.
3. Pick a slot and click `새 게임` (a slot with a saved run asks for a second click). The slot window disappears and the `출정 준비` screen shows Ascension `<`/`>`, rules, `해금`, `출정`, `뒤로`. You stay on the Title; `뒤로` returns to the slot window.
4. Click `해금`: the unlock window opens on top; close it with `닫기`. Click `출정`: the Game scene starts at stage 1 preparation.
5. In the game, lose a battle (or use the temporary defeat button) and choose to return to the title: the Title opens directly on the same slot's `출정 준비` window.
6. Reset: stop Play Mode. Delete test slots from the slot window (`고른 슬롯 삭제` twice).
