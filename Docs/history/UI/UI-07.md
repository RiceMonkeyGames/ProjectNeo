## Delivered (committed earlier on the branch)

- Equipment window (`I`): paper doll with a 3x3 cell block (portrait on the top-left 2x2, five gear slots around it), a stats box at the top-right, and a 3x6 storage grid below. Hover shows an item tooltip with the stat change; click equips, swaps or removes. Item icons are optional (`ItemDefinition.Icon`); an item without an icon shows the first letters of its name. The window uses the UI-12 dark plate with the thick gold `Box22` frame, centered on the screen. `Esc` and `I` both close it.
- Skill tab: tabs `장비` / `스킬` and a hero switcher. The skill view shows the three fixed skills of the selected hero as round slots with grade badges, a details box, and an Auto toggle (heroes only). Skills are no longer on the player loadout; old saves drop it on load.
- Skills are separated from perks: perks grant no skills; the four skill perks are replaced by stat perks. Perks (`K`) stay player-only and in their own window.
- Interaction prompt: under the crosshair, no plate; the interact key is shown as a key cap followed by the action text (for example `상점 사용`). Key caps are generated white rounded 9-slice squares (`Art/UI/SPR_RoundedBox_White.png`) with a 3D base; `F1` and `F10` are separate caps joined by `~`.
- `Esc` pause menu: a full-height left column (260 wide) over the sidebar with `일시정지`, `스테이지 N · 승천 N`, `계속하기`, `저장 후 타이틀로`, the save error line and `Esc 닫기`. Hovered rows turn gold with a diamond (`MenuRowHighlight`). Window colors and frame come from new `HudStyle` window fields (`ProjectNeo/Setup/Window Skin (UI-07)`).

## Squad organization window (`O`) and rule changes (uncommitted in the working tree at the time of this record)

- Three equal-width columns in an 800-wide window (the largest width that clears the 0.8-scale sidebar): column 1 squad list (a `new squad` row at the end, until the cap), column 2 the selected squad (leader slot and soldiers), column 3 stored heroes and soldiers.
- Clicking a row moves it. Column 3 rows join the selected squad; column 2 rows return to storage. No move buttons and no helper captions.
- Leader slot is hero-only and may be vacant. Clicking a stored hero makes them the leader and the previous leader returns to storage. Clicking the leader unassigns them like any other member.
- A full squad dims its column 3 soldier rows and makes them unclickable. Columns scroll when content overflows.
- Rows use one size for all rows; the leader row differs only by a gold thumbnail frame and a `부대장` tag. Thumbnail slots (soldier, hero, leader) stay empty until portrait art exists. Row view: `Runtime/UI/OrganizationRowView.cs`.
- Bottom line: a red `부대 삭제` button left of `편성 확정` deletes the squad selected in column 1 (members return to storage as free soldiers). There is no per-row delete control.
- The resource bar and the clock stay visible while the window is open. Squads are named `1부대`, `2부대`, ... No attack or HP stats are shown in the window.
- Unassigned units stay in storage after confirming and can be taken out later.
- Rule changes (user decision 2026-11-23, supersedes the D-8 rule that soldiers always belong to a squad and empty squads vanish):
  - Soldiers may be unassigned (stored, like heroes). Stored soldiers are hidden in the scene and excluded from battle.
  - Empty squads persist. No empty-squad cleanup runs after battle.
  - Squads are created from the `new squad` row and can be deleted (see above).
  - Recruits (barracks and starting bonus grunts) go straight to storage as free soldiers. The barracks window no longer picks a squad.
  - Caps: 10 squads, 20 soldiers per squad, from `SquadConfig.asset` written by `SquadCapsSetup`.
- Closing: `Esc` or the key that opened the window closes it. Organization: `O` closes it (`PreparationInteraction.OrganizationKeyInPanel`).

## Manual Verification Guide

1. Open `Assets/_Project/Scenes/Game.unity`, Game view 16:9, press Play, start a run.
2. In preparation, first-person: press `O`. Expected: three columns of equal width (squad list, selected squad, stored units), and every row the same height; the leader row differs only by its gold thumbnail frame and the `부대장` tag.
3. Bottom line: the red `부대 삭제` sits left of `편성 확정`.
4. The resource bar (top) and the prep clock (header) stay visible while the window is open.
5. Click a stored soldier in column 3: it joins the selected squad. Click a row in column 2: it returns to storage. Click a stored hero: they become the leader and the old leader returns to storage.
6. Click the `new squad` row at the end of column 1: a new squad appears. Select it and press `부대 삭제`: its members return to storage.
7. Open the barracks (`TrainingGround`) and recruit: the new soldier goes to storage (column 3), hidden in the scene, and no squad is chosen.
8. Press `Esc` or `O` to close the window; then press `O` again and confirm `편성 확정` keeps stored units in storage.
9. Reset: stop Play Mode. If the window layout is missing, run `ProjectNeo/Setup/Connect Squad Organization To Game Scene` with the Editor idle and the active scene saved.
