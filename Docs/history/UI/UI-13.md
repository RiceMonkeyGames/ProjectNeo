## Task record

### Scope & Completion Criteria

Registered 2026-11-24 from the user's request to remake the top-down squad placement screen (`P`, `GamePrepPlacement`, PREP-05). The user picked mockup option B (map markers) and dropped the top-center `부대 배치 / 선택 N부대` plate, because the selection already shows in the left squad cards.

Today the screen has the UI-12 sidebar squad cards plus a two-line text hint at the bottom (`GameFlowHud.PlacementHint`), and nothing on the map itself. Target look:

- Squad number markers over each squad on the map (gold ring, filled gold when selected).
- Ghost markers for each squad's remembered placement (`SquadPlacementMemory`), with a short dashed link to the squad's current spot.
- Castle interior zone outline (`CastleInteriorRules`) so the allowed area is visible; outside the zone is marked as not allowed.
- Front-line drag preview shown as a map marker line (existing `SquadCommandCenter.PreviewLine`), not only the formation preview.
- Key guide at the bottom-right in the UI-12 key cap style (`F1~F10` select, click move, drag front line, `P`/`Esc` back), replacing the long text hint. The warning line (for example `성 밖에는 부대를 배치할 수 없습니다.`) stays as one shadowed line.
- No top-center title plate.

Out of scope: bottom squad tray with click selection (mockup option C), new placement rules. Coordinate with UI-08 (battle HUD, key guide and crosshair) and avoid editing combat code owned by the teammate.
