## Implementation

- `PlayerHealthHud` binds the serialized player `CharacterActor.Health`, subscribes to `Health.Changed`, refreshes immediately on damage/healing/max-HP changes and unsubscribes on disable or replacement. No combat rules, balance, cursor behavior or shared combat-core code changed.
- The authored `GameFlowHUD/PlayerHealth` panel contains a TMP value and non-interactive track/fill images. It uses the existing HUD font/scaler. Bar ratio is clamped; numerical HP rounds upward so a living fractional HP value is not displayed as zero.
- First-person preparation/battle show the panel. Facility/equipment/squad popups, construction/placement views and reward/results hide it. Next preparation restores visibility and uses the current player's health.
- `PlayerHealthHudSetup.Apply` / `ProjectNeo/Setup/Add Player HP HUD` updates the existing hierarchy without duplicates and saves only Game through Editor APIs. It refuses Play Mode and unsaved scene changes. The health controller lives on the HUD root so hiding its content does not disable refresh.
- Final layout: bottom-right anchor/pivot, 240 x 64 reference pixels, right margin 24 and bottom margin 128. The bottom offset reserves the existing 96-high preparation prompt and its margin; initial bottom margin 24 visually overlapped that prompt and was corrected after inspection.
