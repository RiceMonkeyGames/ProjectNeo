- Branch `feature/q-01`; youngho. Doc task plus one Editor-only helper; no game rules or runtime code changed.
- Options presented after reviewing the docs and the `Assets/ThirdParty` submodule (about 95 packs, mostly outside the medieval fantasy style):
  - Packs: (A1) keep the applied packs and fix one main pack per role, (A2) modular characters (`PolygonFantasyHeroCharacters` or `Synty/SidekickCharacters`) for heroes, (A3) Kingdom + Rivals only.
  - Piece specs: (B1) keep 3m cells and 3m tiers and slice-and-tile the Synty battlements, (B2) adopt Synty battlement proportions (cover rule change), (B3) switch to 5m cells (large ripple).
- User decision (2026-11-22): A1 and B1 as recommended, and default castle walls become two stacked tiers (6m) with the 6m main gate. Cover heights (keep 1.1m / 2.2m with stretched meshes, or move toward Synty proportions) stay open until SIEGE-13 starts, with the teammate.
