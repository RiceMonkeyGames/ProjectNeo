## Decision (2026-11-23)

Following team agreement to settle standard configuration choices with conventional defaults, plus user decision on facility scope:

1. **Morale tuning values**: Keep the existing data-asset values in [MoraleAndWave](../../design/MoraleAndWave.md) (`0–200` scale, start `150`, once-per-battle Breaking Point check at `100` with `25%` base Awaken, `>=150` `+10%` / `<100` `-10%` attack bands, post-battle `max(current + 20, 80)`, full-squad casualty drop around `166.7`) as the confirmed baseline defaults. Any further numeric tuning is deferred to M4/M6 balance passes.
2. **Prep-phase morale recovery facility**: Do not add a separate morale recovery facility for now. Post-battle recovery (`max(current + 20, 80)`) plus perks and skills remain the morale recovery paths.
