# Q-78 | 2026-11-20 | Ascension Levels Instead of the Post-Ending Loop

Last Updated: 2026-11-20 13:27:35 (KST)

> Purpose: Decision log. | Parent: [history/README](../README.md) | Related: [Q-69](Q-69.md), [Q-75](Q-75.md), [MoraleAndWave](../../design/MoraleAndWave.md), [PrepEconomyMeta](../../design/PrepEconomyMeta.md#meta-progression), [Decisions-Resolved](../../plan/Decisions-Resolved.md)

- Decided by the user (신용준) on 2026-11-20 at the start of FLOW-03. It supersedes the team meeting decisions Q-69 and Q-75 (a harder loop inside the same run after the ending). Teammate review is pending (SeongminHwang, youngho), because this changes META-04 (score multiplier) and META-08 (run end).
- User's idea: ending the run and making it harder are separate things. Clearing every stage ends the run normally, and the game then offers a harder challenge for later runs, like Ascension in Slay the Spire.
- Options presented: difficulty per level (A) one stacking penalty rule per level, (B) stat % only, (C) both; max level (A) 10, (B) 20, (C) unlimited; rewards (A) score and unlock points scale with level, (B) score only, (C) none; process (A) record now as a new ID with a teammate note, (B) team agreement first. The user chose A, A, A, A.
- Rule: Clearing the last stage ends the run as a victory: the ending screen settles run-end unlock points (META-08) and the run score (META-04). A clear unlocks the next Ascension level (Slay the Spire style), kept in the meta save of the slot; a new run starts at any unlocked level (level 0 is the base game). Each level adds one penalty rule and keeps every lower level's rules. Max level 10 (data; more levels can be added as data). Higher levels multiply the run score and the run-end unlock points by a per-level multiplier (data).
- FLOW-03 proposal approved as-is by the user on 2026-11-20. Rules were chosen to reuse existing data values where possible (enemy stats, `RunConfig.startingGold`, `PrepTimeSettings.budgetHours`/`fullRepairHours`, `MoraleSettings.startingMorale`) and to alternate combat and economy pressure. A steeper multiplier (0.2 per level) was offered as an alternative and not chosen.
- Values (user approval 2026-11-20, FLOW-03; all in data): rules per level, each kept at higher levels: A1 enemy HP +15%; A2 starting gold -25%; A3 enemy attack +15%; A4 prep time budget 12h -> 10h; A5 victory gold reward -20%; A6 enemies per wave +20% (rounded up); A7 squad starting morale 150 -> 120; A8 boss HP +30% and attack +20% (no effect until SIEGE-09); A9 wall repair time x2; A10 enemy move speed +15%. Score and unlock point multiplier x(1 + 0.1 x level) (A10 = x2.0; unlock points rounded up). Only clearing the highest unlocked level opens the next one; clearing a lower level still pays its rewards. The level is picked in a small window after `New Game` on the Title screen (`<` level `>` with the stacked rule list); it is fixed for the run and stored in the run save, so Continue keeps it.
