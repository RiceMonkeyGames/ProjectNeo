# Q-81 — Team Decision: Combat Consumables Expansion, Quick Slots & AI Use

## Scope & Completion Criteria

Decide how combat consumables expand beyond the single healing potion on `Q` (`PREP-04`; [PrepEconomyMeta](../design/PrepEconomyMeta.md), [OpenQuestions](../design/OpenQuestions.md)).

### Decisions Needed

1. **Consumable Varieties**:
   - Decide which consumable types to support beyond instant self-heal (e.g., temporary player stat buff, squad-wide morale tonic, throwable fire/stagger bomb, stamina/cooldown aid).
   - Decide whether consumables share one global cooldown (`10s` currently) or use per-type / per-slot cooldowns.
2. **Quick-Slot UI & Input**:
   - Decide how many quick slots the player gets (e.g., 2–3 slots or a cycle key + single use key `Q`), since `1`/`2`/`3` are already bound to squad commands (`Q-11`).
   - Decide how quick slots are configured during preparation (e.g., inside the `I` inventory window) and displayed in the Battle HUD (`UI-08`).
3. **Hero / AI Consumable Usage**:
   - Decide whether allied heroes or squad captains can use consumables (auto-use from shared run stash, dedicated per-hero slots, or keep consumables player-only).

### Completion Criteria

- Decisions recorded in [PrepEconomyMeta](../design/PrepEconomyMeta.md) and [Decisions-Resolved](../plan/Decisions-Resolved.md).
- Approved scope split into concrete `PREP-*` / `COMBAT-*` / `CONTENT-*` tasks.
