# Q-59 — Team Decision: Building Tier Limits & Edge Cases

## Scope & Completion Criteria

Registered 2026-11-18 from OpenQuestions. Decide max vertical tiers, stair constraints and partial foundation collapse handling.

## Input from SIEGE-14 (2026-11-23)

The 5m castle kit spike ([SIEGE-14](../history/SIEGE/SIEGE-14.md)) already settled parts of this question for the kit, behind `BuildGridDefinition.forbidValleys`: no wall valleys (a top lower than both neighbours on one axis), a collapsed storey takes every storey above it so a fallen wall is rebuilt at full height, automatic stairs between storeys (straight, or quarter-turn on corners), stairs that close a breach stay standing, and towers stack one storey above the touching walls. Still to decide for the Game on 5m tiers: the maximum number of tiers (the spike uses 3 = 15m), the default wall height (`SIEGE-18`), and whether the valley rule is turned on in the Game.
