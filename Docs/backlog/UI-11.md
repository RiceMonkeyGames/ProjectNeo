# UI-11 — Options Window: Key Rebinding

## Scope & Completion Criteria

Registered 2026-11-21 from user request during UI-06. An options window where every key can be rebound: movement, preparation (interact, equipment, organization, placement, battle start, wait), and battle keys (squad select/commands, cannon, ladder, consumables, skills, perks). Opened from a settings button on the Title main menu (after UI-10 merges) and from an in-game pause menu that `Esc` opens when no other window is open. Bindings are saved once per PC, shared by all save slots. Keys today are standalone `InputAction` fields across several settings assets (`PreparationInteractionSettings`, `GameBattleSettings`, `SiegeSettings`, `CannonOperatorSettings`, `SquadCommandSettings`, `PlayerInputController`), with no shared action asset. Battle/squad default keys are confirmed under Q-11 (2026-11-23); coordinate with combat code owners only when changing underlying input actions. Key hints (UI-06 `H` list, HUD prompts) must show the rebound keys. Open before start: duplicate-key handling, reset to defaults, mouse buttons, whether the pause menu pauses time in battle. Style follows UI-06/UI-10.
