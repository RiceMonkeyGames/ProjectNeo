# SIEGE-25 - Piece Balance Pass for the 5m Grid

## Scope & Completion Criteria

Registered 2026-11-23 from the team decision to move the Game to the 5m castle kit ([Decisions-Resolved](../plan/Decisions-Resolved.md)); source: [SIEGE-14](../history/SIEGE/SIEGE-14.md) breakage list items 8 and 10.

- One 5m piece covers about 2.8 times the area of a 3m piece: rebalance wall HP, build and repair cost and time, wall-breaker damage and the cannon blast radius against cells.
- Stairs: one cell over 5m keeps the 45 degree slope; set stair HP relative to walls (spike 50 vs 100, since stairs that block a breach should be easier to break).

Done when the values are updated in data assets, recorded in the design docs and checked in a full Game run.
