## How to List, Read, Claim, and Complete Tasks

- **List tasks (1 call, do not bulk-read `Docs/backlog/`)**:
  `powershell.exe -NoProfile -ExecutionPolicy Bypass -File Tools/Agent/backlog-list.ps1`
  (supports `-Status Waiting`, `-Status "In Progress"`, `-Area <PREFIX>`, `-Assignee <name>`, `-IncludeHistory`).
- **Read a single task**: Open only `Docs/backlog/<TASK-ID>.md`.
- **Register / Claim**: Run `Tools/Agent/claim-check.ps1 -TaskId "<TASK-ID>"`, edit or create only `Docs/backlog/<TASK-ID>.md`, commit and push to `develop`, then branch `feature/<task-id-lowercase>` (or `fix/<task-id-lowercase>`).
- **Complete (after user confirmation)**: Create `Docs/history/<PREFIX>/<TASK-ID>.md` and delete `Docs/backlog/<TASK-ID>.md` (`git rm`). Do not edit this file, [Backlog-Done.md](archive/Backlog-Done.md), [history/README.md](history/README.md), or [plan/Status.md](plan/Status.md) for routine per-task completions.
- **Full rules & frontmatter schema**: See [Collaboration.md](workflow/Collaboration.md).
- **Legacy completed tasks (through 2026-11-21)**: [archive/Backlog-Done.md](archive/Backlog-Done.md) (frozen read-only archive; all new completions live exclusively in `Docs/history/<PREFIX>/<TASK-ID>.md`).
